Release 3.1.0

LEAP- LIVE ENTERPRISE APPLICATION PLATFORM 3.1 (New Features and Enhancements)

LEAP 3.1 introduces new generative AI (gen AI) capabilities and machine learning (ML) to enhance Problem and Service Management. Key highlights include:

  • • Generative AI Capabilities: Create easily searchable knowledge collections with your process documents to assist in ticket resolution. Automate L1 support and improve troubleshooting for L2 tickets.
  • • MFE Architecture: Upgraded architecture for greater flexibility in deployment and overall approach.

LEAP.KG -Knowledge Graph(KG) is a tool for data exploration that visualizes data in the form of graph and allows user to navigate and query the data without any query language or programming. A graph represent data as nodes and relationships each with type and attributes. That makes it easy to represent connected, real world information to find new insights from the data.

SI no Feature Description
1 Metric Metric or KPI can be understood as the business objective that the candidate application aims to achieve using appropriate gamification techniques.
2 Sprint Sprint is defined as a stint (span) within a stipulated time frame for running any competition.
3 Behaviours User behavior is an engagement touch point between the user and the application to be gamified.These behaviors can also be linked with the KPIs (Key Performance Indicators) that a particular application intends to achieve, based upon the game mechanics.
4 Badge A badge represents a special accomplishment, or a symbol of authority. User is given a Badge to recognize his efforts.
5 Rules Rules are used to define criteria on one or more gamification mechanics.Rules define what to do when a particular event (behavior, challenge, treasure hunt, content/content set) is performed in the application.
6 Challenges Challenges are defined in the gamification system to drive user towards certain goal to enhance his degree of performance.
7 Treasure Hunt Treasure Hunt is the group of questions aligned in a sequence, such that unlocking the previous level finds the key to next level.
8 Metaphor Metaphor is the application of external real life paradigm, to existing business processes or applications to make them more interesting.
9 Content Set Each content set will have one or more content in it.
10 Literacy The Literacy feature allows multi-media content to be embedded in an application as a tool to improve knowledge about a topic. It can be used to reinforce domain specific business process knowledge.
11 Redemption This is the redemption service output page in which a user can redeem his points to buy virtual goods.
