🎛️ Available Commands

📋Open Job Logs Viewer

Command: essedum.openJobLogs
Usage: Opens table interface for pipeline jobs

🔧Open Internal Job Logs

Command: essedum.openInternalJobLogs
Usage: Shows internal job-specific logs

💻Show Logs in Terminal

Command: essedum.showJobLogsInTerminal
Usage: Display logs in VS Code output channel

🎨 Features Overview

📊Real-time Updates

Jobs automatically update every 10 seconds when running. Status badges change color based on job state.

🔄Pagination

Navigate through jobs with First, Previous, Next, Last buttons. Configurable page size.

📝Detailed Logs

Click the log button to view complete job data in a dedicated viewer with key-value pairs.

⚡Job Control

Stop running jobs directly from the interface with confirmation prompts.

🎯Output Artifacts

View job output artifacts for remote runtime jobs in a separate panel.

🌈VS Code Integration

Native VS Code theming, command palette access, and output channel integration.

📘 Usage Instructions

1. From Pipeline Cards:

• Navigate to the Essedum sidebar • Find your pipeline card • Click the "View Logs" button • Browse jobs in the table interface

2. Direct Command Access:

• Press Ctrl+Shift+P (Command Palette) • Type "Open Job Logs Viewer" • Enter pipeline name (e.g., "LEORGNGS24627") • View and manage jobs

3. Terminal Output:

• Command Palette → "Show Job Logs in Terminal" • Enter job ID (e.g., "job_12345") • View raw logs in output channel • Dedicated channel per job ID
